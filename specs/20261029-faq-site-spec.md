## 背景・目的

`qa.md` に英語で記載されているFAQコンテンツを日本語化し、バックエンド不要のスタティックなFAQサイトとして提供する。
ハンズオン参加者がブラウザで直接開いて利用できる形にする。

## 現在の挙動

FAQは `qa.md` にMarkdown形式で英語のみで存在し、サイトとしての実装はない。

## 期待する挙動

`faq/index.html` をブラウザで開くと、日本語化されたFAQが表示される。
キーワード検索・カテゴリ絞り込み・アコーディオン展開ができる。

## 対象範囲・対象外

### 対象範囲

* `faq/index.html` の新規作成
* `faq/style.css` の新規作成

### 対象外

* 利用者: ハンズオン参加者
* 影響システム: なし（新規ファイル追加のみ）

## 主な仕様

1. **FAQデータ:** `qa.md` のコンテンツを日本語に翻訳し、HTMLに静的に埋め込む
2. **カテゴリ:** 以下の4カテゴリを設ける
   - 一般
   - 使い方
   - 高度な機能
   - トラブルシューティング
3. **アコーディオン表示:** 各Q&Aはクリックで回答を展開・折り畳みできる
4. **キーワード検索:** 検索ボックスに入力するとQ&Aの質問・回答テキストをリアルタイムで絞り込む
5. **カテゴリ絞り込み:** 「すべて」を含む5つのボタンでカテゴリを絞り込む
6. **組み合わせ絞り込み:** キーワード検索とカテゴリ絞り込みは同時に機能する
7. **該当なし表示:** 絞り込み結果が0件の場合、「該当するFAQが見つかりませんでした」と表示する
8. **外部依存なし:** 純粋なHTML/CSS/JSのみで実装する

## 制約・非機能要件

* バックエンド不要（静的ファイルのみ）
* 外部CSSフレームワーク・外部JavaScriptライブラリ使用禁止
* レスポンシブデザイン（PC・スマートフォン対応）
* シンプル・ミニマルなデザイン

## UI・画面仕様

### 対象画面

FAQサイト（シングルページ: `faq/index.html`）

### 画面構成・表示項目

```
[ ヘッダー: サイトタイトル ]
[ 検索ボックス ]
[ カテゴリ絞り込みボタン: すべて | 一般 | 使い方 | 高度な機能 | トラブルシューティング ]
[ FAQアコーディオンリスト ]
  [ カテゴリヘッダー（カテゴリ別に表示） ]
    [ Q: 質問テキスト  ▼ ]
    [ A: 回答テキスト（展開時のみ表示） ]
    ...
[ フッター ]
```

### 操作・画面遷移

* シングルページ。画面遷移なし
* 検索ボックスへの入力 → リアルタイムでQ&Aを絞り込む
* カテゴリボタンのクリック → 対象カテゴリのQ&Aのみ表示
* キーワード × カテゴリの組み合わせ絞り込みが可能
* Q（質問部分）をクリック → A（回答部分）が展開・折り畳み

### 表示状態

| 状態 | 表示内容 |
|------|----------|
| 初期表示 | 全カテゴリ・全Q&Aを表示。回答はすべて折り畳み状態 |
| 絞り込み結果あり | 条件に合致するQ&Aのみ表示 |
| 絞り込み結果なし | 「該当するFAQが見つかりませんでした」と表示 |

### 入力・バリデーション

* 検索ボックス: テキスト入力（リアルタイム絞り込み）
* バリデーションなし（空文字の場合は全件表示に戻る）

### デザイン要件

* シンプル・ミニマルデザイン
* 純粋なCSSのみ（外部フレームワーク不使用）
* レスポンシブ対応（モバイルファースト推奨）
* アクティブなカテゴリボタンは視覚的に区別できること
